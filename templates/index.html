Privacy Notice

1. Purpose of Processing
VeriChat AI processes the uploaded WhatsApp .txt file to analyze message content for potential scam indicators and generate an overall scam risk assessment and analysis report.

2. Data Processed
The uploaded chat may contain personal information such as names, phone numbers, timestamps, and message content. Users should avoid uploading unnecessary sensitive information.

3. Use of Uploaded Data
Chat content is processed by the system using Natural Language Processing (NLP), TF-IDF feature extraction, and a Naïve Bayes classifier to classify messages and calculate scam probability and risk level.

4. Storage and Retention
The uploaded .txt file is processed for analysis and is not intentionally saved as an uploaded file by the application. Generated analysis reports may be stored by the system for downloading and may contain information from the analyzed chat.

5. User Responsibility
Only upload conversations that you have the right or permission to analyze. Users are responsible for ensuring that the uploaded information is appropriate for analysis.

6. Security
VeriChat AI applies reasonable input validation and processing controls to help protect uploaded information. However, no system can guarantee complete security of data.

7. AI-Generated Results
The results provided by VeriChat AI are AI-generated assessments and should not be treated as definitive proof that a message, transaction, or person is fraudulent. Users should independently verify suspicious content.

8. Consent
By selecting the consent checkbox, you confirm that you have read and understood this Privacy Notice and agree to the processing of the uploaded chat for the stated purpose.

Important: VeriChat AI is an academic project prototype. Please avoid uploading highly sensitive or unnecessary personal information.

9. Personal Data Protection

This Privacy Notice is designed with reference to the relevant principles of the Personal Data Protection Act 2010 (Act 709), including notice and choice, disclosure, security, retention, data integrity, and access.
